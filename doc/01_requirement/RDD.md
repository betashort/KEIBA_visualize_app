# 競馬新聞馬柱表示アプリ 要件定義書

---

## 1. システム概要

### 1.1. システム名

競馬新聞馬柱表示アプリ

## 2. システム目的

* 競馬の出馬表・過去走・予想印などを、競馬新聞風UIで閲覧・分析できるビューアを提供する。

## 3. 想定ユーザー

* 競馬予想ユーザー

<div style="page-break-after: always;"></div>

## 4. システム構成

### 4.1. 概要

* ブラウザに表示する。

### 4.2. フロントエンド

* React
* TypeScript
* Vite

### 4.3. データ

* JSON

<div style="page-break-after: always;"></div>

## 5. 機能要件

### 5.1. レース一覧表示

#### 5.1.1. 概要

* 開催レース一覧を表示する。

#### 5.1.2. 表示項目

**例**
| 項目     | 内容       |
| -------- | ---------- |
| 開催日   | 2026/05/10 |
| 競馬場   | 東京       |
| R        | 11R        |
| レース名 | NHKマイルC |
| 条件     | 芝1600 G1  |

<div style="page-break-after: always;"></div>

### 5.2. レース詳細表示

#### 5.2.1. 概要

* レース概要を表示する。
* 競馬新聞風の馬柱を表示する。
* レース分析結果を表示する。

#### 5.2.2. 表示項目

| 項目           | 説明                       |
| -------------- | -------------------------- |
| レース概要     | レースのサマリ             |
| 馬柱           | 競走馬の出走・過去成績情報 |
| レース分析結果 | レース分析結果             |

<div style="page-break-after: always;"></div>

### 5.3. レース概要表示

#### 5.3.1. 概要

* レース概要を表示する。

#### 5.3.2. 表示項目

| 項目               |
| ------------------ |
| 開催日             |
| 競馬場             |
| 開催日目           |
| 天気               |
| レース名           |
| グレード           |
| クラス             |
| 条件               |
| 距離               |
| 馬場(芝 or ダート) |
| 出走頭数           |
| 同レースのレコード |
| 同レースの傾向     |

<div style="page-break-after: always;"></div>

### 5.4. 馬柱表示

#### 5.4.1. 概要

* 競馬新聞風の馬柱を表示する。

#### 5.4.2. 表示項目

| 大項目      | 小項目                                             |
| ----------- | -------------------------------------------------- |
| 印          |                                                    |
| 枠番        |                                                    |
| 馬番        |                                                    |
| 出走馬情報① | [馬名, 性別, 馬齢, 直近体重, 斤量, ブリンカー使用] |
| 出走馬情報② | [馬主, 厩舎, 生産牧場, 騎手]                       |
| 過去5走     | 過去表示を参照する                                 |

<div style="page-break-after: always;"></div>

### 5.5. 過去走表示

#### 5.5.1. 概要

* 過去レースの成績を表示する。
* 過去5走を「1レース=1セル」で表示する。

#### 5.5.2. 表示項目

| 項目         | 例     |
| ------------ | ------ |
| 日付         | 4/20   |
| レース名     | 皐月賞 |
| グレード     | G1     |
| 競馬場       | 中山   |
| 馬場         | 芝     |
| 距離         | 2000   |
| 着順         | 2着    |
| 走破タイム   | 1:58.4 |
| 上がりタイム | 33.8   |
| 人気         | 1人気  |
