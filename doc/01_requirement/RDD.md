# 競馬新聞馬柱表示アプリ 要件定義書

---

## システム概要

### システム名

競馬新聞馬柱表示アプリ

## システム目的

競馬の出馬表・過去走・予想印などを、競馬新聞風UIで閲覧・分析できるビューアを提供する。

競馬予想に必要な情報を高密度かつ高速に閲覧できることを目的とする。

## 想定ユーザー

* 競馬予想ユーザー

<div style="page-break-after: always;"></div>

## システム構成

### 概要

* ブラウザに表示する。

### フロントエンド

* React

* Vite

## 機能要件

### レース一覧表示

#### 概要

開催レース一覧を表示する。

#### 表示項目

| 項目     | 内容       |
| -------- | ---------- |
| 開催日   | 2026/05/10 |
| 競馬場   | 東京       |
| R        | 11R        |
| レース名 | NHKマイルC |
| 条件     | 芝1600 G1  |

### 馬柱表示機能

#### 概要

競馬新聞風の馬柱を表示する。

#### 表示形式

* 横スクロール型
* 固定ヘッダ
* 馬名列固定（sticky）

#### 表示項目

| 項目       |
| ---------- |
| 印         |
| 枠番       |
| 馬番       |
| 馬名       |
| 性齢       |
| 斤量       |
| 騎手       |
| 単勝オッズ |
| 人気       |
| 過去5走    |

#### 過去走表示機能

##### 概要

過去5走を「1レース=1セル」で表示する。

##### セル表示内容

```txt id="pxpftv"

中山芝2000
2着 1:58.4
上33.8 1人気
```

##### 表示項目

| 項目     |

| 競馬場   |
| 芝/ダ    |
| 距離     |
| 着順     |
| タイム   |
| 上がり   |
| 人気     |

##### 色分け

| 条件   | 色  |
