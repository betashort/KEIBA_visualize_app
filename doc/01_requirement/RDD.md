## 1. システム概要

競馬新聞馬柱表示アプリ

## 4. システム構成

### 4.1. 概要

* デスクトップアプリで動作する（Tauri + React + Rust。詳細は [設計 README](../02_design/README.md) を参照）。

### 4.2. 永続化方針

アプリが参照・更新するデータの**正（マスター）は SQLite** とする。JSON は**取込・交換用**の外部フォーマットであり、ランタイムの単一データソースにはしない。

| 方式 | 役割 | 内容 |
| ---- | ---- | ---- |
| **SQLite** | 正（マスター） | レース・出走馬・過去走などの表示用データ、ユーザーが入力した予想印など、アプリ内で保持・更新するデータ |
| **JSON** | 取込・交換 | 外部ツール等で生成したレースデータの投入フォーマット。取込時に SQLite へ取り込み、以降の表示・操作は SQLite を参照する |

* データはユーザーのローカル環境にのみ保存する（オフライン利用を前提とする）。
* JSON ファイルのスキーマ・ファイル構成、取込手順の詳細は [データ設計書](../02_design/dataDesign.md) で定義する（概要は [基本設計書](../02_design/design.md)）。

### 4.3. データの流れ（概要）

1. **初回／更新時**: 外部で用意した JSON をアプリが読み込み、SQLite に格納（または更新）する。
2. **通常利用時**: SQLite からレース一覧・馬柱・印などを読み書きする。画面表示は SQLite 上のデータを参照する。
3. **エクスポート**（将来対応の場合）: SQLite の内容を JSON 等へ書き出す。MVP で必須としない。

> **設計との整合**: [設計 README](../02_design/README.md) の技術選定（SQLite）を採用する。本要件書の「JSON」は永続化の代替ではなく、**データ投入経路**を指す。

## 5. 画面要件

### 5.1. 画面一覧

| 画面           | 内容           |
| -------------- | -------------- |
| ホーム画面 | 起動後に表示する |

## 6. 機能要件

### 6.1. 機能一覧

| 機能                 | 概要                                      |
| -------------------- | ----------------------------------------- |
| レース一覧表示       | 開催されるレースの一覧を表示する           |
| レース詳細表示       | 選択したレースの詳細情報を表示する         |
| レース概要表示       | レースの開催日や条件などの概要を表示する   |
| 馬柱表示             | 出走馬情報・過去走成績などを新聞形式で表示 |
| レース分析結果表示   | 予想印や独自指標など分析結果を表示する     |
| 印入力機能           | 馬ごとに印（◎、○など）を付与できる         |
| ソート機能           | 馬柱情報を指定順序で並び替えできる         |
| フィルタ機能         | 条件に合致した馬のみを表示できる           |
| 印刷機能             | 印刷用フォーマットで出力・印刷できる       |
